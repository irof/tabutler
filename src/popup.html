グルーピング設定

ルール記述例:

[
  {
    "title": "検索結果",
    "urlPatterns": [
      "https://www.google.com/*",
      "https://www.google.co.jp/*"
    ]
  }
]
  • urlPatternsは 一致パターンで書きます。
  • 保存したものは次にこの画面を開いた際に復元されます。
  • グルーピングは保存していなくても入力内容で行われます。
  • JSON出ないもの、titleやurlPatternsのないものはエラーになりグルーピングや保存は実行できません。
