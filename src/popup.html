説明

グルーピング

「グルーピング設定」に従ってタブを自動的にグループ化します。

掃除

要らないタブを自動的に閉じます。 「要らないタブ」とは空のものや同じURLのものなどです。 何を要らないとするかは「掃除設定」で選びます。

掃除履歴

掃除されたタブを実施時刻、タイトルとともにリスト化します。 閉じたくなかったものはここから開き直せるかもしれません。

並び替え

URL順に並び替えます。 グループ化されたものはグループ内で並び替えます。
グルーピング設定

ルール記述例:

[
  {
    "title": "検索結果",
    "urlPatterns": [
      "https://www.google.com/*",
      "https://www.google.co.jp/*"
    ]
  }
]
  • urlPatternsは 一致パターンで書きます。
  • 保存したものは次にこの画面を開いた際に復元されます。
  • 不正なJSONはエラーになります。グルーピングや保存は実行できません。
